# Номерной

Бесплатная браузерная игра: выбивание российских автономеров с прокруткой символов, коллекция, игровой рынок, ежедневная награда и достижения.

## Возможности

- Три режима выбивания с открытыми шансами и пять уровней редкости.
- Полный перечень регионов с названиями и дополнительными автомобильными кодами; все коды доступны при любой редкости.
- Анимация каждого символа, подсветка редких находок, конфетти и переключаемый звук.
- Гараж с поиском, фильтрами, сортировкой и избранным, защищённым от продажи.
- Продажа по игровой оценке и покупка готовых номеров за виртуальные ₽.
- Личный рекорд, восемь достижений и ежедневные 25 000 ₽.
- Адаптивный интерфейс, клавиатура, поддержка reduced motion.
- Автоматическое сохранение в localStorage этого браузера.

Рынок является локальным игровым магазином. Настоящие деньги, реальные регистрационные знаки, вывод средств, обмен между игроками и серверная синхронизация отсутствуют. Очистка данных браузера удаляет прогресс. Ежедневная награда использует дату устройства. Лимит гаража — 300 номеров.

## Локальный запуск

Нужен любой статический HTTP-сервер. Например, с Python:

```sh
python -m http.server 4173
```

Откройте http://localhost:4173. Проект не требует сборки или установки зависимостей. `index.html`, `app.js`, `game.mjs`, `regions.mjs`, `styles.css` и `favicon.svg` должны лежать вместе. Шрифты Manrope и Oswald загружаются из Google Fonts; предусмотрены системные замены.

## GitHub Pages

Публикация из корня ветки `main` через GitHub Pages. Все пути относительные, поэтому сайт работает и в подпапке репозитория. `.nojekyll` отключает обработку Jekyll.

Исходники: HTML, CSS и нативные JavaScript-модули. Игровая логика отделена в `game.mjs`.

## Справочник регионов

Справочник содержит 174 кода и 90 наименований регионов и специальных территорий. Названия и пул выбивания формируются из единого каталога `regions.mjs`. Основные назначения сверены с [приложением № 1 к приказу МВД № 766](https://sudact.ru/law/prikaz-mvd-rossii-ot-05102017-n-766/) в редакции от 12.11.2025; дополнительные серии — со справочниками [Calc2me](https://calc2me.ru/kod-regiona/) и [ПДД.ру](https://pdd.ru/region-codes). Проверено 13.10.2026. Для переиспользованных кодов используются текущие назначения: 80 — Донецкая Народная Республика, 81 — Луганская Народная Республика, 84 — Херсонская область, 85 — Запорожская область, 88 и 94 — обслуживаемые МВД территории за пределами РФ. Исторические коды 20 и 91 и резервные московские 277 и 299 не участвуют в выбивании.
